## 2025-02-20 - Missing ARIA Labels on Mobile Menu Controls
**Learning:** Found that the main navigation toggle (`.mobile-menu-btn`) and the sidebar close button (`.mobile-close-btn`) lacked accessible names. For screen reader users interacting with this application in Portuguese, it was completely inaccessible. The interface relies on generic `✕` characters and SVGs without text equivalents or `aria-label`s. Also, these buttons act as toggles but didn't have `aria-expanded` state tied to the menu's state (`isMobileMenuOpen`). This is a repeating pattern to watch for across other custom popovers/drawers in this specific app.
**Action:** Always check icon-only interactive controls, especially those for core navigation. Added `aria-label="Abrir menu"` / `"Fechar menu"` and bound `aria-expanded` to the `isMobileMenuOpen` state variable to improve accessibility.
