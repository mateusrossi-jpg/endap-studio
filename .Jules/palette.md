## 2024-05-18 - Missing ARIA labels on mobile menu toggle buttons
**Learning:** Responsive layouts often rely on icon-only buttons for mobile menus (like hamburger or close icons). These interactive elements lack explicit text, making them inaccessible to screen readers unless explicitly labeled.
**Action:** Always ensure that icon-only buttons used for layout toggles or specific actions include descriptive `aria-label`s, maintaining the app's language consistency (e.g., using Portuguese like "Abrir menu" and "Fechar menu").
