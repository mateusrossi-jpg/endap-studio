## 2024-10-24 - Preserving referential equality in simulation loops
**Learning:** The cyclical simulation loop `runScanSimulation` evaluates state every 200ms. If state evaluation functions (like `evaluateRung` and `evaluatePath`) always return new object references even when properties haven't changed, it causes massive cascading React re-renders across the entire ladder program UI, severely degrading performance.
**Action:** When updating complex state in a continuous simulation loop, always compare the new computed state with the previous state. If the actual values haven't changed, return the original object reference to allow `React.memo` components down the tree to bail out of rendering. Ensure stable callback props are used via `useCallback` when using `React.memo`.
