## 2024-05-24 - Unnecessary object creation in runScanSimulation
**Learning:** The `evaluatePath` and `evaluateRung` functions in `ladderRuntime.ts` unconditionally return new object instances (using spread operators and `map`) even when no state changes occur. This causes massive cascading React re-renders because `runScanSimulation` relies on referential equality to avoid unnecessary updates. Returning `nextProject` with newly created nested arrays every 200ms triggers all memoized components down the tree to re-render.
**Action:** Optimize `evaluatePath` and `evaluateRung` to return the exact same object references (`blocks`, `branches`, `rung`) if their internal state didn't change, and only perform shallow clones/updates when necessary. Also use a lazy clone for `nextMemory` instead of unconditionally copying the entire dictionary.
