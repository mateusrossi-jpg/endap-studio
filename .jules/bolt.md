## 2024-10-10 - Optimizing referential equality in high-frequency React cyclical state simulation loops
**Learning:** In cyclical simulation loops (like `runScanSimulation` executing every 200ms) that are tightly coupled to React state, unconditionally recreating root objects or mapping over lists indiscriminately causes massive referential churn. Since React heavily relies on referential equality (`===`) for its rendering bailouts, this churn triggers cascading re-renders across the entire component tree on every tick, even if no values effectively changed.
**Action:** When updating complex state in a loop bound to React, implement lazy evaluation patterns. Ensure that reducers or evaluation functions (e.g., `evaluatePath` and `evaluateRung`) only create new objects, arrays, and dictionaries (`MemoryMap`) when properties have genuinely changed. Use explicit tracking (e.g. `let mutated = false`) and only copy when a modification actually occurs.
