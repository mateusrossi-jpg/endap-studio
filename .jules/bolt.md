## 2026-09-30 - Referential Equality in Simulation Loop\n**Learning:** The 200ms `runScanSimulation` loop was causing cascading React re-renders because `evaluatePath` and `evaluateRung` were unconditionally mapping arrays and shallow cloning state objects (like `MemoryMap` and `EndapLadderBlock`), breaking referential equality even when the underlying values remained unchanged.\n**Action:** Refactored state evaluation functions to strictly preserve referential equality, returning existing references unless properties or nested objects were genuinely modified. This drastically reduces React render cycles.
