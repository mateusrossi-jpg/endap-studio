## 2026-09-23 - Prevent unneeded re-renders in cyclical runtime
**Learning:** React state relies on referential equality to avoid unneeded re-renders. The 200ms `runScanSimulation` simulation loop calls `evaluateRung` which currently maps over all blocks and unconditionally shallow-clones every block (e.g., `return { ...block, active }`) regardless of whether any actual internal state (`active`, `elapsedMs`, etc.) changed. This causes React to constantly re-render components every 200ms even when no values have changed.
**Action:** When updating state iteratively in a loop, avoid unconditional shallow-cloning. Check if the computed value actually differs from the existing value before cloning. If nothing changed, return the original reference to preserve referential equality and prevent massive cascading React re-renders.
