## 2023-10-27 - Preserve React Referential Equality in High-Frequency Cyclical Loops

**Learning:** In a heavily cyclical React app (e.g., 200ms `runScanSimulation` logic execution), blindly cloning entire complex state trees like `project.ladderProgram.rungs` and the large `MemoryMap` dictionary results in extreme performance degradation. React components downstream (e.g. `LadderEditor`, `PropertyPanel`) rely on referential equality to bail out of re-renders (`React.memo`, `useMemo`). If standard shallow-cloning patterns like `.map` or array/object spread operators (`{ ... }`) are used unconditionally every 200ms, all components see "new" references and re-render entirely, choking the UI thread.

**Action:** For loops that repeatedly execute but only occasionally mutate state, strictly implement lazy cloning (also known as structural sharing). Only create new objects (`{ ...block }`), arrays (`[...blocks]`), or maps (`{ ...memory }`) if the internal logic actually caused a mutation. Use strict equality checks (`if (block.active === active) return block;`) and bubble up "change flags" (`blocksChanged = true`) to parents so they can decide whether to reuse their existing array references or clone.
