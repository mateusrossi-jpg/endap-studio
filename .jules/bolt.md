## 2025-05-15 - React Context and Referential Equality Optimization in Cyclical Simulation Loop
**Learning:** In applications relying on a high-frequency cyclical simulation loop (e.g., 200ms `runScanSimulation` in this codebase), unconditionally creating new object/array references (via `.map()` or spread `{...}`) on every tick for unchanged state forces React to perform massive, unnecessary cascading re-renders across all connected components, degrading performance significantly.
**Action:** Always implement explicit referential equality checks in the evaluation logic (`evaluatePath`, `evaluateRung`) to return the original object/array references if the underlying values have not actually changed. This allows React's rendering engine (and `React.memo`) to bail out early and efficiently skip re-rendering the DOM for components displaying static simulation elements.
