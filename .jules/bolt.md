## 2024-05-24 - Referential Equality in High-Frequency Evaluation Loops
**Learning:** The application's `runScanSimulation` runs every 200ms. An initial version of `evaluatePath` and `evaluateRung` unconditionally returned new array and object references for `blocks`, `rungs`, and `memory`, even if no internal properties changed. This destroyed referential equality, forcing massive cascading React re-renders across the entire ladder diagram component tree multiple times per second.
**Action:** When implementing frequent state evaluation loops that drive React UIs, always use a strict copy-on-write strategy. Only clone arrays or objects if a value actually transitions. If the internal state is stable, return the exact original reference to allow React to skip re-renders efficiently.
