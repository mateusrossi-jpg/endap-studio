## 2024-09-11 - React.memo behavior with high-frequency ticks
**Learning:** In a high-frequency tick environment like a simulation runtime (e.g. 200ms scan cycle), using pure functional loops (e.g., `map`) that reconstruct identical state objects at each tick creates new object references. These new references completely bypass component-level `React.memo`, triggering full DOM re-renders even when block/rung state hasn't changed.
**Action:** Always ensure that pure business logic functions are optimized to only return a new object reference (`{...oldObj, prop: newVal}`) if a property genuinely changed. Return the original reference if it hasn't. Combining reference reuse with `React.memo` (and `useCallback` for functions) acts as a highly effective bailout for large, complex structures in React.
