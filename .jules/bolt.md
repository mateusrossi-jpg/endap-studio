## 2023-10-27 - Referential equality loss during scan simulations
**Learning:** In the `runScanSimulation` loop (which runs every 200ms when in `RUN` mode), `evaluatePath` and `evaluateRung` were previously unconditionally returning newly spread objects for blocks and rungs (e.g., `{ ...block, active }`), even if the block state (`active`, `elapsedMs`, etc.) had not actually changed since the last tick. This caused widespread breakdown of referential equality, forcing the entire React component tree for the Ladder Editor to fully re-render on every single simulation scan tick (5 times a second), regardless of whether there was a real state change to display.
**Action:** When working on cyclical state updates or simulation loops, ensure the underlying reducers or state evaluation functions preserve referential equality (`return block`) if the computed new state strictly equals the old state. Combine this with `React.memo` on the rendered items (and stable callbacks) to short-circuit expensive DOM diffing.
