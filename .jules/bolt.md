## 2024-10-03 - Referential Equality in Simulation Loop
**Learning:** The application utilizes a cyclical \`runScanSimulation\` loop that executes every 200ms to evaluate the state of ladder programs. Previously, the core \`evaluatePath\` and \`evaluateRung\` functions in \`src/services/ladderRuntime.ts\` unconditionally cloned objects and arrays (e.g., \`const nextMemory = { ...memory }\` and \`const nextBlocks = blocks.map(...)\`), breaking referential equality on every scan regardless of state changes. This caused massive cascading React re-renders throughout the application on every tick.
**Action:** Implemented a lazy cloning strategy where objects (like \`MemoryMap\`) and arrays are only cloned if their internal values actually change during evaluation. Next time, always ensure simulation core loops preserve referential equality to avoid React rendering bottlenecks.
