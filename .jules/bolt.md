## 2024-05-24 - React Re-renders in 200ms Cyclical Loop
**Learning:** The application's `runScanSimulation` cyclical loop runs every 200ms and updates the entire project state. Previously, the runtime evaluation functions (`evaluatePath`, `evaluateRung`) blindly mapped and spread arrays and objects, creating new referential identities on every tick even if the logical data hadn't changed. This causes React components downstream to re-render constantly, burning CPU cycles unnecessarily.
**Action:** Always verify if an object's state logically changes before recreating it. By preserving referential equality at the source (`ladderRuntime.ts`), we can wrap downstream React components (`LadderRung`, `LadderBlock`) in `React.memo` and avoid massive cascading re-renders during high-frequency simulation updates.
